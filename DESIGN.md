# Chapter visual system

Light product workspace for a developer planning the next session at a desk in daylight. Restrained pine green accents, cool pale gray canvas, white surfaces, charcoal text. Inter sans serif; slightly rounded cards with thin borders. Fixed left navigation, wide project gallery, narrow priority rail. Project previews give each card its own identity. Use quiet 180ms state transitions, no decorative animation. Product states use explicit text and gentle semantic tints. All forms and panels follow the same button and spacing vocabulary.
